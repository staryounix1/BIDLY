What was built

Payments & wallet new

  • Job payment: authorize → capture in one transaction; the provider wallet is credited through wallet_transactions, the platform commission is recorded in platform_earnings, and the job is marked PAID.
  • Paying is idempotent: re-paying returns the captured payment; a prior CAPTURE success row is never charged twice.
  • Failed authorization/capture now sets the payment FAILED, records the failed transaction with an error code, and leaves it retryable.
  • Payouts: requesting one moves funds from available to reserved; admin approval settles reserved, rejection returns it to available — so the same balance can never leave twice.

Signed provider webhooks new

  • POST /payments/webhook/:provider verifies HMAC-SHA256 over the raw body (constant-time compare) before anything is parsed.
  • Events are persisted in webhook_events; the unique (provider, event_id) index makes a replay a no-op that is acknowledged but never applied twice.
  • Signature failures are stored as FAILED and rejected with 401.

Admin console repaired

  • Fixed broken schema references that made every mutating action 500: admin_actions now writes target_type/target_id with the admin row resolved from admins.user_id.
  • Fixed the KPIs query (platform_earnings.recorded_at), the provider queue (display_name, correct enum values, suspension_reason), and audit-log joins.
  • Added money views: payments list + detail, transactions, wallets + per-wallet ledger, and reason-bearing, ledger-backed wallet adjustments.
  • Added request management (list, force-cancel) and catalog management (services list/update, category create).
  • Every endpoint is gated by requirePermission least privilege; a MODERATOR cannot read finance endpoints, and a non-admin gets 403.

Frontend new

  • /[locale]/jobs: a Pay now action appears for completed, unpaid jobs and reports the outcome (paid / failed, retryable).
  • /[locale]/wallet: provider balance (available / reserved / lifetime), ledger table, payout request form and payout history.
  • /[locale]/admin: tabbed console — overview KPIs, payments, transactions, wallets (with adjust), payouts (approve/reject), provider verification, requests, and the audit log. Permission denials surface cleanly.
  • i18n keys (payment, wallet, admin, nav entries) added to Arabic, French and English; RTL preserved.

Web build emits 63 static pages (was 55).
